# RAG Engineering Lab

A Python lab for learning how to build document ingestion pipelines, retrieval-augmented generation systems, and AI agents. The project develops each component incrementally and records the engineering decisions behind it.

## Status

Repository initialization is complete. Document processing is the next phase and awaits approval.

Python 3.12 or newer is the project baseline. The scaffold has no runtime dependencies or application entry points. Dependencies are introduced as implementation phases need them.

## Repository layout

| Path | Purpose |
| --- | --- |
| `src/rag_engineering_lab/` | Reusable Python package |
| `notebooks/` | Experiments and comparisons |
| `tests/` | Automated tests |
| `samples/` | Synthetic or publicly distributable fixtures |
| `docs/architecture/` | Architecture and component status |
| `docs/decisions/` | Architecture decision records |
| `AGENTS.md` | Development rules and conversation responsibilities |

Read the [current state](docs/current-state.md) for the next task, the [roadmap](docs/roadmap.md) for phase acceptance criteria, and the [architecture overview](docs/architecture/overview.md) for the target design.
